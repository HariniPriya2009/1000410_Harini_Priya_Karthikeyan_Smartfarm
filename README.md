# 1000410_Harini_Priya_Karthikeyan_Smartfarm

**🌾 Smart Farming AI Assistant – Kerala Edition**

An intelligent, bilingual (English & Malayalam) AI-powered web application designed to support farmers in Kerala with practical, localized agricultural advice.
Built using Streamlit, SQLite, and Google Gemini AI, this assistant helps farmers make informed decisions related to crops, soil, pests, weather challenges, and seasonal planning.
**Project Overview**

Farmers often lack timely, expert guidance tailored to their local conditions.

This project aims to bridge that gap by providing:

Location-aware farming advice

Simple, farmer-friendly explanations

Bilingual responses (English & Malayalam)

Secure user profiles for personalized guidance

The system stores farmer details and uses AI-powered reasoning to generate short, actionable recommendations.

**Objectives**

Provide accurate agricultural guidance for Kerala farmers

Support different farming types (paddy, coconut, spices, vegetables)

Enable personalized advice based on farmer profile

Offer easy-to-use web interface

Encourage smart, sustainable farming practices

**How the AI Works**

Farmer logs in or creates a profile

Farmer selects a challenge or types a custom question

Farmer profile data is combined with the question

Gemini AI generates localized farming advice

Output is displayed in a clear, bullet-point format

**Language Support**

English

Malayalam

Both (based on user preference)

The AI adapts responses to ensure simple, easy-to-understand language suitable for farmers.
